# CodeForge Neon

Cyberpunk-themed Codeforces practice website, built from a downloaded archive of public problem statements and sample tests.

## GitHub Pages
Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
Select **main** and **/(root)**, then Save.

Open `https://ak16082008.github.io/Codeforge_neon/` after deployment.

Problem links open `problem.html?id=...` in a new browser tab.
Code editing is local; C++/Python compilation and Codeforces hidden tests are not included.
